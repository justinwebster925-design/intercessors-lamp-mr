# The Intercessor's Lamp MR 
**Platform: Meta Quest 3S (Mixed Reality)**

## Concept
A spiritual defense simulation that uses Spoken Authority to combat psychological and metaphysical threats in an immersive MR environment.

## Technical Stack
- **Engine:** Unity 2022.3 LTS
- **SDKs:** Meta XR Interaction SDK, Meta Voice SDK (Wit.ai)
- **Mechanics:** Spoken word recognition used as a primary game mechanic for "casting" defense.
